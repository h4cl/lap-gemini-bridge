# Dataset — Anticipation

Casos de espera, expectativa ou acoplamento externo.

Exemplos:
- esperar mensagem;
- aguardar aprovação;
- esperar resposta profissional;
- atualizar app ou email repetidamente.

Estados prováveis:
- Coupled resonance
- Metastable
- Recursive
- Saturated

Pergunta principal:
> O LAP consegue modelar dependência de evento externo sem inflar metáfora?
