# Dataset — Conversation Loops

Casos em que uma conversa terminada continua ativa internamente.

Exemplos:
- replay de mensagens;
- simulação de respostas;
- espera por retorno;
- ruminação social;
- reinterpretação tardia.

Estados prováveis:
- Recursive
- Metastable
- Coupled
- Decaying

Pergunta principal:
> O LAP ajuda a distinguir processamento útil de ruminação improdutiva?
