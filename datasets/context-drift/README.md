# Dataset — Context Drift

Casos de deriva de foco, contexto ou intenção.

Exemplos:
- entrar para fazer uma tarefa e sair em outra;
- cadeia de abas;
- conversa com mudança de centro;
- agente perdendo foco em long context.

Estados prováveis:
- Turbulent
- Decaying
- Fragmented
- Drift-high

Pergunta principal:
> O LAP melhora detecção e reancoragem de deriva contextual?
