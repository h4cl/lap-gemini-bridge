# LAP Datasets

Este diretório armazena casos observacionais do LAP.

Objetivo:
transformar o LAP de linguagem conceitual em prática comparável.

Cada dataset registra:
- estado bruto humano;
- compressão LAP;
- resposta Gemini;
- auditoria Claude;
- síntese Nyx;
- intervenção proposta;
- efeito real observado;
- nível de utilidade.

## Regra

Nenhum dataset prova consciência, ontologia ou verdade científica.

Datasets servem para testar utilidade operacional, repetição e clareza.

## Estrutura

```text
datasets/
  conversation-loops/
  microcompensation/
  creative-reverberation/
  anticipation/
  context-drift/
  _schemas/
  _templates/
```

## Critério de valor

Um caso só é útil se responder:

> o LAP tornou o estado mais claro, mais acionável ou mais observável?
