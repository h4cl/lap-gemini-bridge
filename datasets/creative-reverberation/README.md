# Dataset — Creative Reverberation

Casos em que uma atividade criativa terminou, mas o campo continua ativo.

Exemplos:
- terminar de tocar guitarra;
- encerrar escrita;
- parar uma edição;
- sair de uma ideia criativa ainda viva.

Estados prováveis:
- Harmonic
- Decaying
- Quiescent
- Residual resonance

Pergunta principal:
> O LAP diferencia reverberação criativa saudável de loop improdutivo?
