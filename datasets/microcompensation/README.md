# Dataset — Microcompensation

Casos em que o corpo executa pequenas ações automáticas para quebrar um estado mental.

Exemplos:
- abrir a geladeira sem fome;
- pegar o celular sem intenção;
- trocar de aba sem motivo;
- levantar para buscar algo desnecessário.

Estados prováveis:
- Metastable
- Weak-recursive
- Substitution loop
- Decaying

Pergunta principal:
> O LAP identifica a função real do gesto automático?
