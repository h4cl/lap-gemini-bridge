# Operational Boundaries

## O que o LAP NÃO afirma

- Não prova consciência artificial.
- Não mede experiência subjetiva absoluta.
- Não acessa estados mentais reais.
- Não transforma metáforas em matemática literal.
- Não substitui neurociência, psicologia ou diagnóstico clínico.

## O que o LAP tenta fazer

- Criar linguagem operacional para estados semântico-fenomenológicos.
- Modelar persistência, dissipação, recursão e drift.
- Coordenar modelos com papéis funcionais.
- Registrar logs comparáveis.
- Testar se a compressão LAP produz utilidade prática.

## Critério de sobrevivência

O LAP só continua se gerar pelo menos um dos seguintes efeitos:

1. maior clareza operacional;
2. melhor intervenção comportamental;
3. melhor coordenação inter-modelos;
4. melhor rastreamento de contexto;
5. melhor geração criativa controlada.
