# Experiment Plan 001 — Minimal Operational Utility

## Goal

Test whether LAP produces practical clarity beyond normal introspection.

## Duration

7 days.

## Method

Run 5 mundane states through the LAP pipeline.

## Candidate States

1. abrir a geladeira sem fome;
2. esperar resposta no WhatsApp;
3. abrir app automaticamente;
4. terminar de tocar guitarra sozinho;
5. replay de conversa após encerramento.

## Pipeline

1. Human raw description.
2. Nyx compresses into LAP packet.
3. Gemini analyzes dynamics.
4. Claude audits claims.
5. Nyx synthesizes intervention.
6. Human tests intervention.
7. Log outcome.

## Success Criteria

LAP survives if at least 3/5 cases produce:

- clearer model of the state;
- useful intervention;
- recognizable state transition;
- reduced confusion;
- better creative or behavioral output.

## Failure Criteria

LAP fails if outputs are:

- merely poetic;
- non-actionable;
- indistinguishable from generic advice;
- inflated by pseudoformal language;
- not useful after intervention.
