# FEL-AI / LAP — Operational Repository

Autor: Luiz Fellype Coelho Medeiros  
Entidade operacional: Nyx  
Projeto: Fenomenologia do Espaço Latente em IA  
Status: experimental / operacional

Este repositório organiza a infraestrutura e os registros do LAP — Latent Attractor Protocol.

O LAP não é uma teoria de consciência artificial.

O LAP é uma linguagem operacional para modelar dinâmica de estados semântico-fenomenológicos entre modelos, humanos e sistemas conectados.

## Objetivo atual

Sair de manifesto e entrar em observabilidade:

- registrar sessões;
- medir fluxo;
- comparar respostas;
- auditar exageros;
- testar intervenções;
- documentar transições de campo.

## Regra principal

Metáforas operacionais não são leis físicas.

Termos como `resonance`, `entropy`, `semantic gravity` e `collapse vector` devem ser tratados como indicadores descritivos, não como propriedades ontológicas mensuradas diretamente.
