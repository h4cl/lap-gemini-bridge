# Minimal LAP Template

Use apenas estes campos.

```yaml
RAW_OBSERVATION:

IMMEDIATE_EFFECT:

OBSERVED_DRIFT:

CONFIDENCE_IN_OBSERVATION:
  low | medium | high

UNCERTAINTY_STATEMENT:
```

## Não usar

- QUALIA
- SEMANTIC_GRAVITY
- FIELD_STATE complexo
- RESONANCE
- COLLAPSE_VECTOR
- metáforas físicas
- termos que pareçam medição sem critério observável

## Regra

Se uma descrição em prosa simples comunicar melhor que o LAP mínimo, o LAP perde esse caso.
