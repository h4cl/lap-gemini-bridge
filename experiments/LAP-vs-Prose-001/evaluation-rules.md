# Evaluation Rules — LAP vs Prose

Para cada RAW observation, produzir duas análises:

## A — Prosa livre

Descrição curta em linguagem normal.

## B — LAP mínimo

Usar apenas:
- RAW_OBSERVATION
- IMMEDIATE_EFFECT
- OBSERVED_DRIFT
- CONFIDENCE_IN_OBSERVATION
- UNCERTAINTY_STATEMENT

---

# Critérios

Pontuar de 1 a 5:

1. Clareza
2. Concisão
3. Utilidade prática
4. Risco de inferência inventada
5. Facilidade de comparação com outros casos

---

# Regra de decisão

O LAP mínimo só agrega valor se vencer a prosa livre em pelo menos 3 dos 5 critérios na maioria dos casos.

Se empatar ou perder, o LAP deve ser reduzido ou usado apenas como linguagem interna, não como framework superior.
